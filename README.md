English Club opens with a room, a sentence, and a gentle nudge to speak. It does not greet a visitor with an institutional wall of facts. Instead, it asks them to choose a conversational move, try a tiny prompt, and see what kind of community might be waiting on the other side.

That choice shapes the whole project. English appears as a social habit rather than a worksheet subject; photographs act as evidence, big type gives each page one clear thought, and orange only arrives when somebody needs to act. The result feels like an editorial club journal that happens to contain a serious practice system and a rather busy publishing room behind the scenes.

## The room introduces itself

The public tour begins quietly. About explains the club's belief in the “next sentence,” while Activities turns speaking, exchanging, making, and staying in the room into four ways to begin. Programs carries those conversations into workshops and community work. Members gives responsibility a face without confusing a profile with permission to publish a portrait.

## Practice, with its claims kept honest

The Assessment Lab knows the difference between practice and prophecy. A learner can open a full 140-question paper-based form or take a shorter skill sprint. Before an attempt begins, the page explains timing, anonymous same-device persistence, scoring limits, and what the result can actually say.

![English Club Assessment Lab](docs/showcase/practice.png)

The full form carries Listening, Structure and Written Expression, and Reading across a 115-minute session. The shorter routes reuse reviewed questions without pretending that eight questions can predict an admission result.

## Behind the blue door

The public site gets the large type; the admin workspace gets the clipboards. Its compact blue-and-orange interface separates page copy, stories, programmes, contact messages, member consent, media, colour recipes, practice formats, and owner-only history. Every area carries its own review boundary, so “saved” and “published” never have to mean the same thing.

## What holds it together

- **Next.js 16.3.2 and React 19.2.8** render the public and protected route trees, metadata, responsive interactions, and theme boot.
- **Convex 1.45** stores public copy, stories, programs, members, messages, practice definitions, attempts, results, and audit events.
- **Convex Auth** gives administrators password identities and creates anonymous identities only after a learner starts persisted practice.
- **Cloudflare R2** stores reviewed public media; Convex keeps the object metadata and publication decision.
- **Tiptap 3** powers structured journal editing, including reviewed inline media.
- **TypeScript, Vitest, Playwright, and Testing Library** keep server rules, UI contracts, accessibility behaviour, and full browser journeys under test.

The public interface follows one cobalt-and-chalk reading system built around Bricolage Grotesque. Administration deliberately changes register: compact panels, hard functional borders, clear state chips, and no attempt to dress publishing work as a lifestyle page.

## Running it locally

The app expects Node.js 20.9 or newer and an existing Convex Cloud development deployment. Runtime data and authentication do not use a local Convex backend.

```bash
npm install
npx convex dev --configure existing --dev-deployment cloud --once
npm run dev
```

It opens at [http://localhost:3987](http://localhost:3987). Public environment names live in [`.env.example`](.env.example); real values belong in `.env.local` and never in Git.

The full local check is:

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

Deployment setup, R2 boundaries, administrator provisioning, and consent rules live in [`SETUP.md`](SETUP.md).

## A note about the people in the room

The current development member directory contains explicitly fictional profiles and generated portrait material. They exercise the real filtering, role, division, and consent contracts, but they do not claim to represent a production roster. Real names and photographs belong here only after the relevant permission has been recorded.

The same plain-dealing rule applies to practice. Results come from original English Club questions and a published internal formula; they are not official ETS scores, certificates, or admission evidence.

English Club is still happiest when the software disappears for a moment and somebody tries the next sentence. That is the small idea every route is carrying.
